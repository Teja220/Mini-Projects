# Python Fun Game Projects

## About Me
While learning Python, I created a series of engaging and interactive projects to apply programming concepts in a fun and practical way. These projects include a variety of games and utilities, showcasing my ability to implement different algorithms and user interactions.

## Projects
This repository features a range of Python projects, such as the **BMI_CALCULATOR.py**, which computes Body Mass Index, and **Band_name_generator.py**, which creates unique band names. The **Blackjack_game.py** offers a simplified version of the classic card game, while **CaesarCipher.py** implements encryption and decryption techniques. **Calculator.py** provides a basic arithmetic calculator, and **Coffeemachine.py** simulates a coffee machine with resource management. The **Fizzbuzz.py** project is a standard programming exercise, and **Hangman.py** is a word-guessing game with a **hangman_art.py** and **hangman_words.py** for game visuals and word lists. **Higher_lower_game.py** challenges players to guess if the next number is higher or lower, supported by **higher_lower_art.py** and **higher_lower_game_data.py**. The **Leap_year.py** script determines leap years, while **Number_Guess.py** involves guessing a randomly generated number. **PasswordGenerator.py** creates random passwords, **Pizza_calculator.py** calculates pizza costs, and **Tip_calculator.py** computes tips and totals. Finally, **Treasure_Island.py** is an interactive text adventure game, and **rock_paper_scissors_game.py** is a classic game of Rock, Paper, Scissors. 

Feel free to explore and enjoy these projects!
